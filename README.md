# Skills

Skills for agents (Claude Code, Codex, Gemini and others that read `SKILL.md`).

| Skill | What it does |
| --- | --- |
| [view-sweep](view-sweep/SKILL.md) | A page transition for switching a long page between two versions of itself, in place: the page eases back, a soft wave travels down and the new version appears behind it. |

## Install

```bash
npx skills add jordialmanza-ram/skills --skill view-sweep
```

View Sweep draws its wave with [glimm](https://glimm.dev) by Noman (MIT); install it in your project with `npm install glimm`.
